# Privacy Policy & Telemetry Notice - TheraVox AI

TheraVox AI is dedicated to privacy-first emotional wellness.

## 1. Telemetry and Analytics Policy

- **Anonymized IDs**: All analytics event logs use SHA-256 hashed distinct IDs. We do not store raw emails, names, or unhashed user identifiers in analytics streams.
- **No Speech or Audio Stored**: Audio recordings analyzed for emotion recognition are processed transiently in memory and immediately discarded.
- **Zero Content Harvesting**: Journal text and chat messages are never used for third-party AI training.
- **Opt-Out Control**: Users can request data deletion or export their complete record via the Profile settings page.

## 2. Collected Event Categories

- Account Activity: Register, Login, Token Refresh
- Feature Usage: Text Emotion Analysis, Audio SER Analysis, Vision Frame Processing, Chat Messages, Breathing Coach, Postcards
- Safety Events: Crisis Detection Trigger (severity score logged anonymized, message text scrubbed)
